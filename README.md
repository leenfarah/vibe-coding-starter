# Mon premier projet vibe codé

Projet de départ du cours **Vibe coding et collaboration** (UX UI 2e année · L'École de design Nantes Atlantique · Media Design lab).

## Démarrer

1. En haut de cette page : **Use this template › Create a new repository**. Propriétaire : **votre compte** (pas l'organisation). Visibilité : **Public**.
2. Dans votre nouveau dépôt : **Code › Codespaces › Create codespace on main**.
3. Ouvrez le panneau **Copilot** et décrivez la page que vous voulez.
4. Pour voir la page : clic droit sur `index.html` › **Show Preview** (ou **Open with Live Server**).

## Ce que contient le projet

| Fichier | Rôle |
| --- | --- |
| `index.html` | La structure : ce qu'il y a sur la page |
| `css/style.css` | L'apparence : couleurs, tailles, espacements |
| `js/main.js` | Le comportement : ce qui se passe quand on agit |
| `AGENTS.md` | Les règles que l'IA doit suivre dans ce projet |

## Mettre la page en ligne

**Settings › Pages › Deploy from a branch › main / (root) › Save**. Votre page sera à l'adresse `https://votre-pseudo.github.io/nom-du-depot/`.

Votre dépôt est public : n'y mettez jamais de mot de passe, de clé d'API ou de données personnelles.
