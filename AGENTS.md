# Règles pour l'assistant de code

Ce fichier dit à l'IA comment travailler dans ce projet. On le complètera en séance 2.

## Le projet
- Une page web statique : HTML, CSS et JavaScript, sans framework ni outil de build.
- Publiée avec GitHub Pages depuis la branche `main`.

## Organisation des fichiers
- La structure dans `index.html`, l'apparence dans `css/style.css`, le comportement dans `js/main.js`.
- Ne pas créer d'autres fichiers sans le dire.

## Façon de travailler
- Faire une seule modification à la fois, petite, et expliquer en deux phrases ce qui a changé et dans quel fichier.
- Écrire un HTML accessible : vrais boutons, textes alternatifs, contrastes suffisants, focus visible.
- Ne jamais écrire de mot de passe, de clé d'API ou de donnée personnelle dans le code.
- Si une demande est floue, poser une question plutôt que deviner.
